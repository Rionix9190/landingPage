# Blossom Shine Salon

A responsive salon landing page for Blossom Shine, built with plain HTML and CSS.

## Live Demo

[View the live website](https://codedbyahmad.github.io/landingPage/)

## Features

- Responsive layout for desktop and mobile screens
- Salon services section with real service images
- Hero section with salon branding and call to action
- WhatsApp booking links with a pre-filled message
- Testimonial, contact, and footer sections

## Built With

- HTML5
- CSS3
- Flexbox

## Run Locally

Open [`index.html`](./index.html) in a browser, or serve the project with any local static web server.
